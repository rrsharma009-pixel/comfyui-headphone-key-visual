# Headphone Key Visual — ComfyUI Assessment

## Project Overview
A cinematic headphone product advertising key visual created using ComfyUI and Krea 2 Turbo.

## Files
- `HeadPhone.png` — final generated key visual
- `Headphone_Krea2.json` — ComfyUI workflow
- `README_Headphone_Krea2.md` — detailed workflow documentation

## Workflow
The ComfyUI workflow generates a cinematic product image with a focus on composition, lighting, materials, and advertising-quality presentation.

## Usage
1. Open ComfyUI.
2. Load `Headphone_Krea2.json`.
3. Ensure the required models and custom nodes are installed.
4. Run the workflow to reproduce the result.
